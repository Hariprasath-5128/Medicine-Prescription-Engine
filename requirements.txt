# torch is deliberately NOT pinned in this file.
#
# Listing it here breaks the CUDA install: `pip install -r requirements.txt`
# pulls the default PyPI wheel (CPU or cu121), and a later
# `pip install torch --index-url .../cu128` is then a NO-OP, because the
# installed version already satisfies the requirement. The result is a torch
# that silently runs on CPU - an 8-hour job becomes a week.
#
# Install torch FIRST, from the index matching your GPU:
#   Blackwell / RTX 50-series (sm_120):
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#   Ampere / Ada (RTX 30xx / 40xx):
#     pip install torch --index-url https://download.pytorch.org/whl/cu121
#
# Then verify: python scripts/04_train_qa_dora.py --check
